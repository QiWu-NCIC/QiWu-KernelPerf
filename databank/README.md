# QiWu Databank

Static leaderboard for the unified QiWu-KernelPerf repository. Reviewed source
lives only in `../KernelPerf/submissions`; `public/source` is generated by the
build script and is not a second source tree.

```bash
npm ci
npm run audit:spmv
npm run dev
```

Node.js 20+ is required. The browser calculates GFLOP/s, efficiency, geometric
means and the 90% coverage rule. A method below 90% successful coverage remains
visible with failure counts but is marked `Unranked`.
